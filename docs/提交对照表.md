## 二、支付宝 Skill Pay 提交流程

1. 浏览器打开 **https://skillpay.alipay.com** ，用支付宝账号登录
2. 进入 **创作后台 / 我的货架**（`/creator/shelf`）
3. **签署协议**：SkillPay 协议 + AI 按量付费协议
4. **新建 Skill**，按上表填名称、简介、分类、标签、图标
5. **上传技能包** `api-batch-tester-v4.0.0.zip`
6. **设置价格** 为 `0`（免费）
7. **提交审核** → 通过后点发布
8. 发布后拿到公开链接：`https://skillpay.alipay.com/public/<你的后缀>`

> ⚠️ **公开链接后缀发布后不能随意更改**，定稿前想好（建议直接用 `api-batch-tester`）。

## 四、双投的注意事项

| 事项 | 建议 |
|---|---|
| 版本一致性 | 两边都发 `4.0.0`，改版时同步升，避免用户在两个平台装到不同版本 |
| slug 一致性 | 都用 `api-batch-tester`，方便你后续做统一跳转链接 |
| 描述一致性 | 用同一份文案，减少维护成本 |
| 谁先发 | 先发你更熟悉后台的那个；另一个照着抄，10 分钟能搞完 |
| 数据看什么 | 各平台后台的**安装量 / 调用量 / 收藏数**——两周后对比，决定后面主推哪个 |

## 五、审核可能被卡的三个点（提前准备）

1. **"技能描述与实际能力不符"** —— 我们的描述与 `SKILL.md` 完全对齐，且附了真实自检报告，这条风险低
2. **"缺少可验证证据"** —— 直接把 `data/_selftest_report.md` 的内容或截图放进商品详情，证明它真能跑
3. **"技能包结构不符合规范"** —— 若平台要求特定目录结构（如必须含 `manifest.json`），按后台提示调整；我们的包是标准 `SKILL.md + scripts + references` 结构，通常可直接用
