**详细描述（商品页正文，可直接粘贴）：**

```
把手动点接口的活儿交给它。

给一份 OpenAPI 3.x / Swagger 2.0 文档（本地文件或 URL）或一份简易接口清单，
它会在几秒内完成下面全部动作：

1. 解析 spec，提取接口清单与参数定义
2. 为每个接口派生三类用例：
   · 正常用例 —— 按 schema 填好必填参数与请求体
   · 异常用例 —— 抽掉必填参数 / 传错类型 / 发送畸形 JSON
   · 边界用例 —— 超长字符串 / 越界数值 / 非法枚举
3. 并发发起真实 HTTP 请求（可配并发数、超时、重试）
4. 逐条断言：状态码是否符合 spec、响应是否为合法 JSON、
   是否包含声明的必需字段（对象与数组元素都校验）、响应耗时
5. 产出 Markdown 测试报告 + 可复现的 JSON 用例集

报告会明确告诉你：测了几个接口、几个有问题、最需要关注的是哪个、
以及每个失败用例的请求地址、实际状态码和响应片段。

适合：上线前体检、接口改版后的回归确认、CI 里加一道接口门禁。

特点：
· 零第三方依赖即可运行（标准库实现；环境里有 requests 会自动加速）
· 所有结论来自真实 HTTP 响应，绝不编造结果
· 技能自带端到端自检脚本，可自行验证引擎行为
```

**标签 / 触发词：**

```
API测试、接口测试、批量测试、接口回归、接口体检、Swagger测试、OpenAPI测试、接口压测
```

**目标用户：** 后端开发、测试工程师、API 设计师、DevOps
